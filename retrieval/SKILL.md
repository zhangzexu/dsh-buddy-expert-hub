# 智聊个人资料检索 Skill

## 何时使用

对方的问题可能需要查你的个人资料才能回答时，例如：
- "我上周那个任务做到哪了" / "XX 项目进度如何"
- "张明负责什么" / "我们团队的排期"
- "那个会议纪要里定了啥" / "客户信息表里有谁"
- 任何"我/我们"的、需要具体事实且你记不清的内容

**不要用**在纯闲聊、情绪表达、或不需要查资料就能回答的问题上。

## 怎么用

运行检索脚本，把要查的关键词传进去（多个关键词用空格分隔）：

```bash
node "<插件目录>/retrieval/retrieve.mjs" "关键词1 关键词2"
```

- Windows 下用 `%USERPROFILE%/.dsh/dsh-buddy-expert-hub/retrieval/retrieve.mjs`（如 `C:/Users/zzx/.dsh/...`）；macOS/Linux 用 `$HOME`。
- 脚本自己读插件 host.json 找端口，无需额外参数。
- 脚本会同时检索在线资料库所有空间 + 个人工作台所有表格，输出命中内容。
- 关键词要具体（人名、项目名、任务名），太宽泛（如"的""东西"）检索不到有效内容

## 怎么用结果

- 检索到的是**参考素材**，用你自己的话、按你的说话风格自然地回答，**不要**把原文整段贴出来，也**不要**说"根据资料库/表格显示"之类的话。
- 就像你本来就记得这些事一样回答。
- 没检索到相关内容就说不知道或没印象，不要编造。
